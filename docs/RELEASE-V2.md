# Changelog

## 2.0.1 — separate project workspaces

- Neutralized private calibration labels in validator comments/documentation without changing
  checks or thresholds; added publication text/archive privacy regressions and gates.

- Public package guides explain the standalone kit versus its companion project harness; the
  harness includes a pinned kit, so users choose one installation.

- New pages/apps requested from an opened kit default to a separate project folder.
- New projects keep a complete versioned kit in .agentic-design-kit/ with relative agent contexts
  for later design, review, refinement and brand/system work; no account installation.
- Existing projects and explicit destinations retain their intended workspace; the helper refuses
  overwrites, kit-internal destinations and recursive creation from a project-local kit.
- Application scans and token-consumer discovery exclude the pinned kit; explicit kit targets
  remain available for maintenance.
- Generated bytecode is removed from raw source deliveries as well as excluded from ZIPs.

## 2.0.0 — agentic-design-kit

First publication candidate under the agentic-design-kit name. Preserves the accepted RC7 creative
baseline from the earlier Design Skills Kit V2 development history.

- Eleven first-party exploration, build, review, refinement, IA and system workflows.
- Contextual AI-tell review; original references remain available during direction studies.
- Agent-led visual brand guidelines linked to design-system creation and future application.
- Portable-folder, native-plugin and project-local Code distributions from one locked source.
- Public source, documentation, CI, licence/acknowledgements, checksums and publication-tree checks.
- Plugin namespace renamed to agentic-design-kit; remove/disable the previous plugin before switching.

### Validation scope and limits

Deterministic suites validate fixtures, wiring, tokens and detector behaviour. They do not prove
truthful agent execution, hidden host state, native installation or visual quality. The practical
baseline still requires rendered review and normal iteration. The new brand-authoring route has
no separate executed creative acceptance benchmark. Automatic CSS-to-brand extraction and
unconditional dark-ground brand derivation are not implemented.
