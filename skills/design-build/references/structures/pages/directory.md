# `directory` — Directory

## Shape

A directory of things the product connects to or works with, grouped and searchable.

## Reach for it when

There are many real integrations, partners or members.

## Avoid when

There are a handful (list them in a sentence); the logos are not real.

## Treatments

- **Section heads:** group heads by kind.
- **Body:** body is name and what it does with the product.
- **Dividers:** dividers are row lines.
- **Buttons:** each entry links to its own page.
- **Images:** logos only when supplied, one size.
- **Reveal:** no entrance animation.

## Variation settings

- **presentation:** rows · compact-grid
- **search:** none · instant-filter

Change at least one when this structure is used again (`check-distance.mjs`).

## Mobile

Groups become disclosures; search stays on top.
