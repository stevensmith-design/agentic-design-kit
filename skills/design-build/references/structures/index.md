# Structure library — index

**On demand only.** Open this file when the committed direction leaves page structure open, then
open only the files you pick — or, for a selected or picked starter, only the files its composition
names. Never on reference-led, reference-directed, named-starter-match or contract-led
approved-direction work, and never while reviewing: there the contract or the system is the
vocabulary, and a library shape in context pulls the page toward it.

The library is theme-free: structures and parts describe relationships, not looks. Any of them can
be built in any direction. Offer **three** structures with a reason from the brief for each, and
let the brief, not habit, choose; never default to the first one listed.

Line format (read by `check-records.mjs` and `check-paths.mjs`): `` - `id` (family) — path — what it
is ``.
