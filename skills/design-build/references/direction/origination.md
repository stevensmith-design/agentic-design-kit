# Origination — directions without references

On demand: the brief-originated route, in `/design-build` or `/direction-study`, once the person
has handed the choice over or declined the inspiration brief (`discovery.md`). Without references
the agent's defaults fill every open decision, and defaults converge on one tidy house style. This
file is a method for making decisions instead. It sets no aesthetic and lists no styles.

## Method

1. **Name the obvious idea and discard it.** Write down the direction anyone would reach for with
   this content and category — usually the category's current house style. Say it in one line,
   then do not build it. Return to it only if every alternative fails the brief.
2. **Find the source world.** Ask what artefact this content would live in if it were not a web
   page: where it would be printed, filed, posted, sold or consulted, and by whom, before screens.
   Derive it from the content's subject, its audience and how it is used — never from a stock
   list or from what looks fashionable. Each direction in a study takes a different source world
   when the content supports more than one.
3. **Borrow the conventions, not the clichés.** Take the world's grid, type behaviour, numbering,
   captions, rules, paper and ink logic — how it organises and signals. Leave its props (fake
   stains, torn edges, stock ornaments, pastiche lettering) behind.
4. **One signature move, one recorded break.** Each direction commits to one move a reader would
   remember and one deliberate break from a default (the obvious grid, the expected type pairing,
   the safe ground), written in the contract with its reason.

## Designed, not generated — tests

Run them on the direction before the build and again on the first render:

- **Swap test** — could another site's text be dropped in without anything feeling wrong? Then
  the design does not belong to this content yet.
- **Name the decision** — point to one choice a default would not make, and say why this content
  asked for it.
- **Real contrast** — scale, density, quiet against loud. A page where everything is evenly medium
  has no hierarchy to read.
- **From the content's world** — at least one element comes from the source world: a convention,
  a numbering system, a way of captioning, a material.
- **Restraint, not blandness** — one strong move with everything else quiet is restraint. No move
  at all is blandness, however clean it looks.

A failed test is a reason to revise the direction, not a checklist item to patch on the render.

## Read register

For long-form reading, keep the text column calm: measure, size, leading and contrast follow
`rules.md`, and nothing competes with the line. Put the expression in the frame — masthead, title
setting, section openers, figures, pull quotes, notes and the end of the piece. A reader should
recognise the direction in the frame and forget it in the paragraph.

## Then

Values for the palette and type come from `custom-direction.md`; a recorded override of one of its
defaults belongs to this step's break. Contrast, legibility and accessibility stay binding.
