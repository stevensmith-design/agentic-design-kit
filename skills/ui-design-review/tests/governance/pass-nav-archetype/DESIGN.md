# DESIGN.md
## Component rules
### Navigation
- **Archetype:** detached floating pill — the product is a swipe-first matching
  tool, and a detached pill keeps the card stack the page's centre of gravity.
- **Destinations:** 3 (How it works, Features, Privacy)
- **Collapse behaviour:** below 768px the row collapses into a disclosure sheet
  opened by `.nav-toggle`, which appears at the same breakpoint.
### Buttons
- Primary: solid fill, 44px
