# Northgate

Machine-readable design spec. This is the google-labs `design.md` format that other design tools
emit — a different shape from this kit's four-layer DESIGN.md.

The collision this fixture pins: the kit's governance checks read PROSE — an `## Override Log`
section, a `### Navigation` archetype entry, a declared control floor in sentence form. Against
this file every one of them greps, finds nothing, and passes. A silent pass is worse than a
failure, because the reviewer reads it as coverage.
