# DESIGN.md — Marketing site

## Palette
- Surface: `--surface` #FFFFFF
- Primary anchor: `--primary` #4C1D95 (violet)
- Radius: `--radius-md` 8px, `--radius-lg` 16px

## Button roles
- Primary CTA uses the solid `--primary` fill.
- Gradient fills are a Tier-2 gated pattern. To use one, a dated Override-log
  entry must be recorded and pre-date the use, then referenced from
  `scan-exceptions.conf`.
