# Waveguide

A live wire: a cool white page whose first screen sends a real request and shows the real response.

## Suits

APIs, developer platforms, data services.

## Avoid

Products that cannot be called from a page; non-technical audiences.

## Axes

axes: ground=light display=sans accent=blue

## Surface and colour

Cool near-white; ink a deep blue-grey; an electric blue accent for the request line and primary
action.

## Type roles

A technical grotesque for display; the same for text; mono for requests, responses and labels. No
italic display.

## Composition

Structures: `workbench`, `walkthrough`, `directory`. Parts: `split-pair`, `spec-table`,
`three-zone-bar`, `category-index`.

## Object family

Requests, responses, status codes, latency figures — all real.

## Signature moves

1. A request and its live response side by side in the first screen.
2. Status codes and timings shown as measured, never invented.
3. A copy button on every code block.

## Motion

The response streams in as it really arrives; reduced motion shows it whole.

## Ambition

Floor: the example works. Target: a developer tries it within a minute. Ceiling: an editable
request.

## Limits

Accent at most 5 % of any viewport band. Never show a response the API did not return; label sample
data.
