# Phosphene

A terminal at night: mono headings, plain text, one glowing ink, and commands as navigation.

## Suits

Developer tools, CLIs, infrastructure, technical writing.

## Avoid

Consumer brands, anything for non-technical audiences.

## Axes

axes: ground=dark display=mono accent=green

## Surface and colour

Dark blue-black ground; ink a soft off-white; one phosphor green (or amber) for prompts, links and
the cursor. No glow effects — the colour does the work.

## Type roles

Mono for display and labels; a plain sans for running text (a mono-only page fails long reading). No
italic display.

## Composition

Structures: `workbench`, `index-first`, `walkthrough`. Parts: `command-line-bar`, `command-entry`,
`step-sequence`, `single-line`.

## Object family

Real commands, real output, prompts, file trees.

## Signature moves

1. Navigation written as a prompt line.
2. Real command output in the first screen.
3. Section heads prefixed with a prompt symbol.

## Motion

A static cursor; no blinking. Typed-out text is not used — output appears whole.

## Ambition

Floor: real commands that work. Target: an engineer trusts it. Ceiling: a live terminal workbench.

## Limits

Accent at most 5 % of any viewport band. Code blocks scroll inside themselves; nothing scrolls the
page sideways at 320px.
