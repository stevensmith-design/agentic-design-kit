# Provisional reference visual guide — one source at a time

Use during reference-led study. Keep it short and beside the actual original; unknowns are valid.
This guide describes a visual language before proposing directions, not an approved production system.

```markdown
# Visual guide — <source>
Original: <viewable path or URL>
Inspection: <what was actually viewed; viewport/crop; date>
Requested use: <faithful style | loose inspiration | selected contributions; actual answer locator>
Defining traits: <3–5 concrete observations summarising the source>

| Axis | Observed relationship and visible evidence | Confidence / unknowns |
|---|---|---|
| Colour | Canvas/surfaces/ink/actions/accents/graphics; placement and approximate coverage | |
| Type | Display/body/label character, hierarchy, scale and spacing | |
| Layout/rhythm | Alignment, density, whitespace and reusable spatial relationships | |
| Components | Geometry, borders, fills and repeated treatments | |
| Imagery/graphics | Medium, crop, placement, prominence and relationship to text | |

Values: <measured/verified values; clearly labelled estimates; unknown font names or states>
Identity-bound material: <marks, copy or proprietary assets that must not transfer>
```

After proposing a direction, link this guide in its contract and record what it preserves, adapts,
and departs from. Keep the observation column unchanged when project requirements force a departure.
Do not turn an inferred colour or proposed font substitute into a source fact.
