# Decision provenance — explain the proposed direction

Write after the direction has been proposed. Provenance is a review aid, not an ideation input or a
permission gate.

Also record:

- identity-bound qualities explicitly not taken;
- interface copy invented beyond the supplied brief;
- any decision whose basis remains uncertain.

If a major device has no honest basis, flag it for the post-exploration review. Do not automatically
remove a useful visual idea merely because it cannot be reduced to a compliance field.
