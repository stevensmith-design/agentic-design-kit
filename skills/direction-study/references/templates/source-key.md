# Optional source key — access and custody aid

Use only when paths are ephemeral, sources are numerous or a person requests an audit trail. It helps
keep originals accessible; it is not required before ideation and does not anonymise sources from the
designer.

```markdown
# Source key — <project>

| ID | Original path or URL | Staged path | Media kind | Required? | Render check | Disposition |
|---|---|---|---|---|---|---|
| S1 | | <optional stable copy> | still · motion · URL | project-dependent | pending · rendered · failed | pending · assigned · unassigned · excluded by person |

## Custody failures
| ID | Attempt | Result | Person decision |
|---|---|---|---|
| | | | replacement requested · optional · exclusion approved |
```

`rendered` means the pixels or motion were displayed successfully. A missing essential source is a
named limitation; nonessential custody paperwork never blocks the first creative pass.
