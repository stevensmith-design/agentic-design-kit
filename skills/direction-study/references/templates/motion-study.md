# Motion study — what a moving reference actually does

Use for any reference whose value is in its motion. Inspect the motion itself; a poster frame is
identification, not evidence. Keep this study beside the original clip and let the designer reopen both.

| Field | Record |
|---|---|
| Source inspected | clip path or URL, duration, how many frames or passes were viewed |
| Held states | the distinct configurations the motion rests in |
| Transition verbs | how it moves between held states, in plain verbs |
| Trigger | scroll · pointer · time · navigation · none |
| What it communicates | the meaning the movement carries; "liveness" alone is not enough |
| Idle behaviour | what happens when nothing triggers it |
| Touch / mobile | the equivalent without hover or a pointer |
| Reduced motion | the static composition that keeps the meaning |
| No-JavaScript fallback | what remains readable without script |
| Not taken | the source's specific motion signature left behind |

A direction that uses motion carries the relevant observations into its contract. Render a reduced-
motion composition when motion is material to judging the proof.
