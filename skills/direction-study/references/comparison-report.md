A recommendation is not a verdict. A failed direction is reported, not repaired during comparison.

No positive recommendation for confirmed genericness, obvious AI-default construction, or missing
required review. Warn, remove while preserving evidence, rerun from the original premise, or
recommend none. Keep initial failed proof and review artifacts when presenting a new version.

Name the actual runtime and execution mode, verified kit root, workflows selected, executed and
completed, and any missing evidence. Folder execution is never reported as native skill activation.
A file-read list is not a completed-workflow record.
