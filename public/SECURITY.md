# Security

The kit supplies agent instructions and local checks. Review files and scripts before running them.
It contains no runtime updater, credential store, hooks or external-service configuration.
Agent tools and host permissions determine what a workflow can access; the kit is not an isolation
boundary. Only run code, browser targets and input files appropriate to your project.

Report vulnerabilities through the repository's private vulnerability reporting when available.
Otherwise open a non-sensitive issue requesting a private reporting route; do not post credentials
or exploit details publicly. No private reporting address or response-time guarantee is asserted.
